# 🚀 START TUTAJ - Najprostszy przewodnik

## 3 kroki do uruchomienia

### 1️⃣ Zainstaluj (2 min)

```bash
cd email-sequence-agent/backend
npm install
```

### 2️⃣ Uruchom (1 min)

```bash
npm run dev
```

Otwórz: **http://localhost:3002**

### 3️⃣ Skonfiguruj przez Dashboard (5 min)

1. W sekcji **🔑 API Configuration** wklej:
   - **Anthropic API Key** (pobierz z: https://console.anthropic.com/)
   - **Test Email** (Twój email do testów)

2. Kliknij **💾 Zapisz**

## ❓ Co jeśli coś nie działa?

### Brak Node.js?
Zainstaluj: https://nodejs.org/ (wersja 18+)

### Błąd Google Auth?
Potrzebujesz:
1. Google Cloud Service Account (credentials JSON)
2. Google Sheets API włączony
3. Arkusz udostępniony Service Account

**Wszystko opisane w [INSTRUKCJA_URUCHOMIENIA.md](./INSTRUKCJA_URUCHOMIENIA.md)**
